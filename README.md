# 🏫 SCHOOL 13 — Roguelite Survival

2D top-down roguelite survival shooter, созданный на React 19, HTML5 Canvas и Google Gemini API.

> Выживи в бесконечных волнах школьного кошмара: сражайся с педсоветом, собирай лут, прокачивай пушки и используй ультимейты!

## ✨ Особенности

- **Оружие и турели:** Рогатка, дробовик, гвоздомёт, кислотомёт, тесла-пушка, баррикады.
- **Ультимейты:** 
  - *Сандевистан* — остановка времени и хроно-залп
  - *Клинок Шиноби* — теневая казнь и телепортация
  - *Звонок на перемену* — оглушающая звуковая волна
- **Боссы:** Физрук, Завуч, Директор школы и безумные лабораторные эксперименты.
- **Мета-прогрессия:** Скины персонажей, постоянные апгрейды характеристик и ачивки.
- **Gemini AI Integration:** Интеллектуальные сценарии и динамические события.

## 🚀 Быстрый старт

1. **Установка зависимостей:**
   ```bash
   npm install
   ```

2. **Настройка окружения:**
   Скопируйте `.env.example` в `.env.local` и укажите `GEMINI_API_KEY`:
   ```bash
   cp .env.example .env.local
   ```

3. **Запуск в режиме разработки:**
   ```bash
   npm run dev
   ```
   Откройте [http://localhost:3000](http://localhost:3000) в браузере.

4. **Сборка проекта:**
   ```bash
   npm run build
   npm run preview
   ```
